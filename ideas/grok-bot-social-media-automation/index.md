## What the eventual bot template is meant to do (per article)

Help an operator run a **first social post end-to-end** with Grok Bot: dispatch (統籌) → Social draft → Mac Codex/Claude Code execute → Notion draft store → human approval → Metricool schedule (IG / Threads / FB) → early daily scan → confirm the post is actually public. Human keeps topic choice and final review; bots do not publish without explicit approval.
